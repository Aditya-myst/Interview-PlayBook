# DBMS & SQL Interview Handbook

## The Complete Guide to Cracking Database Interviews

---

### Why DBMS & SQL Matters

Every top company tests database knowledge. Not just "write a SELECT query." They want you to:
- **Design schemas** (ER Model, Normalization)
- **Understand internals** (Indexing, B-Trees, Query Optimization)
- **Write complex queries** (Window Functions, CTEs, Recursive Queries)
- **Explain trade-offs** (SQL vs NoSQL, Sharding vs Replication)
- **Debug performance** (Execution Plans, Index Usage)

**DBMS knowledge separates candidates who use databases from candidates who understand them.**

---

### What Interviewers Actually Ask

They won't ask "What is a primary key?" That's too basic.

They'll ask:

> "Design a database for a social media platform."
> "What's the difference between clustered and non-clustered indexes?"
> "Write a query to find the second highest salary."
> "Explain ACID properties with examples."
> "How would you optimize this slow query?"
> "When would you use NoSQL over SQL?"
> "Explain the CAP theorem."

**This book prepares you for those questions.**
