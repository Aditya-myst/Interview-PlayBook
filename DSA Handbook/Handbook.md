# DSA Patterns Handbook

## The Complete Guide to Recognizing Algorithmic Patterns in Coding Interviews

---

### Why This Book Exists

You've solved 300 LeetCode problems. You can binary search, you can DFS, you can write a linked list reversal from memory. But when an interviewer gives you a *new* problem—one you haven't seen before—you freeze.

**The problem isn't that you don't know enough algorithms. The problem is that you don't recognize which algorithm to use.**

This handbook teaches **pattern recognition**. Not memorization. Not "tricks." A systematic way to look at a problem and think:

> "This isn't Problem #42. This is Sliding Window with a validity condition I need to define."

---

### How to Use This Book

**Don't read it cover to cover.** That's how textbooks work, not how skill acquisition works.

Instead:

1. **Pick one pattern.** Start with whichever you're weakest at—or start with Sliding Window (highest ROI for interviews).
2. **Read the chapter.** Understand the mental model and the trigger words.
3. **Solve 3 Easy problems** using only the template. Don't deviate. Build muscle memory.
4. **Solve 2 Medium problems** where the pattern isn't obvious. This trains recognition.
5. **Revisit a week later.** Try to solve a Medium without looking at the template. If you can't, repeat steps 3-4.
6. **Move to the next pattern.**

At **5 problems per pattern × 16 patterns = 80 problems total**, you'll have a transferable toolkit that covers the vast majority of interview questions.

### What Each Chapter Contains

Every pattern chapter follows the same structure:

1. **What It Is** — Plain English explanation
2. **When to Use It** — Recognition triggers and decision framework
3. **Mental Model** — How to think about it visually
4. **Brute Force → Optimized** — The journey from naive to efficient
5. **The 80% Template** — The reusable skeleton that solves most problems in the category
6. **Variations** — Sub-patterns and edge cases
7. **Common Mistakes** — Bugs that catch everyone
8. **Dry Run** — Step-by-step walkthrough on a real problem
9. **Code in 4 Languages** — Python, Java, C++, JavaScript
10. **Practice Problems** — Curated LeetCode problems from Easy → Hard
11. **Recognition Exercises** — Problems where the pattern is disguised
12. **Interview Tips** — What interviewers look for
